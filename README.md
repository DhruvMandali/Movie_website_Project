🎬 Movie Website Project

🌟 Project Overview

Movie Website is a full-stack web application designed to provide users with a smooth and engaging movie browsing experience

The Movie Website is a web-based application that allows users to explore movies, view movie details, search for movies, and manage their favorite movies.

Users can create an account, log in, add reviews, and manage their favorite movies. The project also includes an Admin Panel to manage registered users, monitor activities, and manage movie reviews.

This project was developed to improve my practical skills in frontend development, backend development, database management, API integration, and deployment.

## 🎯 Use Cases

The Movie Website provides different functionalities for three types of users:

### 👀 1. Visitor (Guest)

Visitors can explore the website without creating an account.

- 🎬 Browse available movies.
- 🔍 Search for movies.
- 📄 View movie details.
- 👀 Explore movie information and posters.
- 🔐 Register or log in to access user features.

### 👤 2. Registered User

Registered users can access personalized features after logging in.

- 🔐 Register and log in to their account.
- ❤️ Add and remove movies from favorites.
- ⭐ Submit movie reviews.
- ✏️ Edit their own reviews.
- 🗑️ Delete their own reviews.
- 📋 View their favorite movies.
- 🚪 Log out securely.

### 🛠️ 3. Administrator (Admin)

Administrators can manage and monitor the website through the Admin Dashboard.

- 📊 View dashboard statistics.
- 👥 View registered users.
- ✏️ Update user details.
- 🗑️ Delete user accounts.
- 📋 Monitor user activity logs.
- 📝 View and manage movie reviews.
- ❌ Delete inappropriate reviews.
